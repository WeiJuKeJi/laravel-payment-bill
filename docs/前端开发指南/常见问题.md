# 常见问题

本文档整理了前端集成过程中的常见问题和解决方案。

## 🔐 认证相关

### Q: 如何处理 Token 过期？

**A:** 在 Axios 响应拦截器中统一处理 401 状态码：

```javascript
axios.interceptors.response.use(
  response => response.data,
  error => {
    if (error.response?.status === 401) {
      // 清除本地 token
      localStorage.removeItem('auth_token');

      // 跳转登录页
      window.location.href = '/login';

      // 或使用路由跳转（Vue Router / React Router）
      // router.push('/login');
    }
    return Promise.reject(error);
  }
);
```

### Q: 如何刷新 Token？

**A:** 可以在请求拦截器中检查 Token 是否即将过期，提前刷新：

```javascript
// 假设 token 包含过期时间
function isTokenExpiringSoon(token) {
  // 解析 token 获取过期时间
  // 如果距离过期不到 5 分钟，返回 true
}

axios.interceptors.request.use(
  async config => {
    const token = localStorage.getItem('auth_token');

    if (token && isTokenExpiringSoon(token)) {
      // 刷新 token
      const newToken = await refreshToken();
      localStorage.setItem('auth_token', newToken);
      config.headers.Authorization = `Bearer ${newToken}`;
    } else if (token) {
      config.headers.Authorization = `Bearer ${token}`;
    }

    return config;
  }
);
```

## 📤 文件上传相关

### Q: 上传大文件时超时怎么办？

**A:** 增加 Axios 的超时时间：

```javascript
const request = axios.create({
  baseURL: '/api/payment-bill',
  timeout: 60000, // 增加到 60 秒

// 或在单个请求中设置
uploadLocalBillFiles(data, {
```

```ini
# php.ini
upload_max_filesize = 20M
post_max_size = 20M
max_execution_time = 300
```

### Q: 如何实现上传进度条？

**A:** 使用 Axios 的 `onUploadProgress` 回调：

```javascript
// Vue 示例
const uploadProgress = ref(0);

await axios.post('/api/upload', formData, {
  onUploadProgress: (progressEvent) => {
    uploadProgress.value = Math.round(
      (progressEvent.loaded * 100) / progressEvent.total
    );
  }
});

// React 示例
const [uploadProgress, setUploadProgress] = useState(0);

await axios.post('/api/upload', formData, {
  onUploadProgress: (progressEvent) => {
    setUploadProgress(
      Math.round((progressEvent.loaded * 100) / progressEvent.total)
    );
  }
});
```

### Q: 批量上传文件时如何显示每个文件的进度？

**A:** 需要单独上传每个文件：

```javascript
const uploadFiles = async (files) => {
  const results = [];

  for (let i = 0; i < files.length; i++) {
    const file = files[i];
    const progress = ref(0);

    try {
      const result = await uploadSingleFile(file, {
        onProgress: (p) => {
          progress.value = p;
          // 更新 UI 显示第 i 个文件的进度
        }
      });
      results.push({ file, result, success: true });
    } catch (error) {
      results.push({ file, error, success: false });
    }
  }

  return results;
};
```

### Q: 如何限制上传文件的格式和大小？

**A:** 在文件选择前进行验证：

```javascript
// Vue (Element Plus)
const beforeUpload = (file) => {
  const isCSV = file.type === 'text/csv' || file.name.endsWith('.csv');
  if (!isCSV) {
    ElMessage.error('只能上传 CSV 文件！');
    return false;
  }

  const isLt10M = file.size / 1024 / 1024 < 10;
  if (!isLt10M) {
    ElMessage.error('文件大小不能超过 10MB！');
    return false;
  }

  return true;
};

// React (Ant Design)
const beforeUpload = (file) => {
  const isValidType = file.type === 'text/csv' || file.name.endsWith('.txt');
  if (!isValidType) {
    message.error('只能上传 CSV 或 TXT 文件！');
    return Upload.LIST_IGNORE;
  }

  const isLt10M = file.size / 1024 / 1024 < 10;
  if (!isLt10M) {
    message.error('文件大小不能超过 10MB！');
    return Upload.LIST_IGNORE;
  }

  return false; // 阻止自动上传
};
```

## 🐛 错误处理

### Q: 如何统一处理 API 错误？

**A:** 在响应拦截器中统一处理：

```javascript
axios.interceptors.response.use(
  response => response.data,
  error => {
    let message = '操作失败';

    if (error.response) {
      const { status, data } = error.response;

      // 验证错误 (422)
      if (status === 422 && data.data?.errors) {
        const errors = Object.values(data.data.errors).flat();
        message = errors[0] || '验证失败';
      }
      // 业务错误
      else if (data.msg) {
        message = data.msg;
      }
      // HTTP 状态码错误
      else {
        const messages = {
          400: '请求参数错误',
          401: '请先登录',
          403: '无权限访问',
          404: '资源不存在',
          500: '服务器错误',
        };
        message = messages[status] || `请求失败 (${status})`;
      }
    }
    // 网络错误
    else if (error.request) {
      message = '网络请求失败，请检查网络连接';
    }
    // 其他错误
    else {
      message = error.message || '未知错误';
    }

    // 显示错误消息
    if (window.$message) {
      window.$message.error(message);
    }

    return Promise.reject({ message, error });
  }
);
```

### Q: 如何处理部分成功的情况（207 状态码）？

**A:** 单独处理 207 状态码：

```javascript
try {
  const result = await uploadFiles(data);

  if (result.code === 207) {
    // 部分失败
    message.warning(
      `部分文件上传失败：成功 ${result.data.created}，失败 ${result.data.failed}`
    );

    // 显示详细信息
    const failedFiles = result.data.details.filter(d => !d.success);
    console.log('失败的文件:', failedFiles);
  } else if (result.code === 200) {
    // 全部成功
    message.success('所有文件上传成功！');
  }
} catch (error) {
  // 完全失败
  console.error('上传失败:', error);
}
```

### Q: 如何显示详细的验证错误？

**A:** 提取并显示每个字段的错误：

```javascript
// Vue 示例
const handleValidationError = (errors) => {
  Object.keys(errors).forEach(field => {
    const messages = errors[field];
    ElMessage.error(`${field}: ${messages.join(', ')}`);
  });
};

// React 示例
const handleValidationError = (errors) => {
  Object.keys(errors).forEach(field => {
    errors[field].forEach(msg => {
      message.error(msg);
    });
  });
};

// 使用
try {
  await uploadFiles(data);
} catch (error) {
  if (error.response?.status === 422) {
    handleValidationError(error.response.data.data.errors);
  }
}
```

## 🎨 UI/UX 相关

### Q: 如何防止用户重复提交？

**A:** 在上传过程中禁用提交按钮：

```javascript
// Vue
const uploading = ref(false);

const handleSubmit = async () => {
  if (uploading.value) return;

  uploading.value = true;
  try {
    await uploadFiles(data);
  } finally {
    uploading.value = false;
  }
};

// React
const [uploading, setUploading] = useState(false);

const handleSubmit = async () => {
  if (uploading) return;

  setUploading(true);
  try {
    await uploadFiles(data);
  } finally {
    setUploading(false);
  }
};
```

## 🚀 性能优化

### Q: 如何优化大量文件的上传性能？

**A:** 使用并发控制：

```javascript
// 控制并发数量
async function uploadWithConcurrency(files, concurrency = 3) {
  const results = [];
  const executing = [];

  for (const file of files) {
    const promise = uploadSingleFile(file).then(result => {
      executing.splice(executing.indexOf(promise), 1);
      return result;
    });

    results.push(promise);
    executing.push(promise);

    if (executing.length >= concurrency) {
      await Promise.race(executing);
    }
  }

  return Promise.all(results);
}
```

### Q: 如何在开发环境配置代理？

**A:** 配置开发服务器代理：

```javascript
// vite.config.js (Vite)
export default {

module.exports = {

// setupProxy.js (Create React App)
const { createProxyMiddleware } = require('http-proxy-middleware');

module.exports = function(app) {
  app.use(
    '/api',
    createProxyMiddleware({
      target: 'http://localhost:8000',
      changeOrigin: true,
    })
  );
};
```

### Q: 如何调试 API 请求？

**A:** 使用 Axios 拦截器打印请求信息：

```javascript
// 请求拦截器
axios.interceptors.request.use(config => {
  console.log('Request:', {
    method: config.method,
    url: config.url,
    data: config.data,
    headers: config.headers,
  });
  return config;
});

// 响应拦截器
axios.interceptors.response.use(
  response => {
    console.log('Response:', {
      status: response.status,
      data: response.data,
    });
    return response;
  },
  error => {
    console.error('Error:', {
      status: error.response?.status,
      data: error.response?.data,
      message: error.message,
    });
    return Promise.reject(error);
  }
);
```
