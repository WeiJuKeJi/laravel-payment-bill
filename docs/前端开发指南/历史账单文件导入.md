# 历史账单文件导入

本文档介绍如何通过 Web 界面批量上传历史账单文件。

## 📋 功能概述

由于微信支付接口仅支持下载最近3个月的账单，你可以通过此功能手动上传从微信支付后台下载的历史账单文件。

**主要特性：**
- ✅ 支持批量上传多个账单文件
- ✅ 自动解析文件名中的日期
- ✅ 支持微信月账单按交易时间自动拆分为日账单
- ✅ 支持强制覆盖已存在的记录
- ✅ 可选择自动触发账单数据导入任务
- ✅ 详细的导入结果反馈

**注意：** 批量上传的文件数量受服务器配置限制，详见[服务器配置指南](../服务器配置指南.md)。

## 🔌 API 接口

### 端点信息

```
POST /api/payment-bill/local-bill-files/import
```

### 请求头

```
Authorization: Bearer {token}
Accept: application/json
Content-Type: multipart/form-data
```

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| payment_channel_id | integer | 是 | 支付渠道ID |
| files[] | file[] | 是 | 账单文件数组（CSV/TXT格式） |
| bill_type | string | 否 | 账单类型，默认 ALL |
| bill_period | string | 否 | 账单周期，默认 `day`；微信月账单传 `month` |
| force | boolean/string | 否 | 是否强制覆盖已存在记录，默认 false |
| auto_import | boolean/string | 否 | 是否自动触发数据导入任务，默认 false |

**注意：** `force` 和 `auto_import` 参数支持多种格式：
- 布尔值：`true` / `false`
- 字符串：`"true"` / `"false"` / `"1"` / `"0"` / `"yes"` / `"no"`
- 数字：`1` / `0`

### 文件要求

- **格式**：CSV 或 TXT
- **命名（日账单）**：文件名必须包含日期，支持以下格式
  - `YYYY-MM-DD_ALL.csv`（如 `2022-07-24_ALL.csv`）
  - `YYYYMMDD.csv`（如 `20220724.csv`）
- **命名（月账单）**：`bill_period=month` 时不依赖文件名日期，会按文件内 `交易时间` 拆分为每日账单记录
- **大小**：单个文件最大 50MB
- **数量**：取决于服务器配置，默认 PHP 限制为 20 个。如需上传更多，请参考[服务器配置指南](../服务器配置指南.md#文件上传配置)

### 微信月账单导入

上传微信商户平台导出的月账单时，设置 `bill_period=month`。系统会：

1. 读取月账单 CSV 表头中的 `交易时间` 列。
2. 按交易日期拆分为多份日账单文件。
3. 为每个交易日期创建或更新一条 `BillDownload` 记录。
4. 如果启用 `auto_import`，逐日派发微信账单导入任务，流水进入 `payment_bill_wechat_bills`。

当前月账单拆分只支持微信账单；支付宝仍按日账单文件导入。

- **404**：资源不存在
- **500**：服务器错误

## 💻 代码示例

### 原生 JavaScript + Fetch API

```javascript
async function uploadBillFiles(channelId, files, options = {}) {
  const formData = new FormData();

  // 添加支付渠道ID
  formData.append('payment_channel_id', channelId);

  // 添加文件
  files.forEach(file => {
    formData.append('files[]', file);
  });

  // 添加可选参数
  if (options.billType) {
    formData.append('bill_type', options.billType);
  }
  if (options.billPeriod) {
    formData.append('bill_period', options.billPeriod);
  }
  if (options.force !== undefined) {
    formData.append('force', options.force ? 'true' : 'false');
  }
  if (options.autoImport !== undefined) {
    formData.append('auto_import', options.autoImport ? 'true' : 'false');
  }

  try {
    const response = await fetch('/api/payment-bill/local-bill-files/import', {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${localStorage.getItem('auth_token')}`,
        'Accept': 'application/json',
      },
      body: formData
    });

    const result = await response.json();

    if (response.ok || response.status === 207) {
      return result;
    } else {
      throw new Error(result.msg || '导入失败');
    }
  } catch (error) {
    console.error('上传失败:', error);
    throw error;
  }
}

// 使用示例
const fileInput = document.querySelector('#fileInput');
const files = Array.from(fileInput.files);

uploadBillFiles(1, files, {
  force: false,
  autoImport: true
})
  .then(result => {
    console.log('导入结果:', result);
    alert(`导入完成！成功: ${result.data.created}, 跳过: ${result.data.skipped}, 失败: ${result.data.failed}`);
  })
  .catch(error => {
    console.error('导入失败:', error);
    alert('导入失败: ' + error.message);
  });
```

### Axios

```javascript
import axios from 'axios';

async function uploadBillFiles(channelId, files, options = {}) {
  const formData = new FormData();

  formData.append('payment_channel_id', channelId);
  files.forEach(file => formData.append('files[]', file));

  if (options.billType) formData.append('bill_type', options.billType);
  if (options.force !== undefined) formData.append('force', options.force ? 'true' : 'false');
  if (options.autoImport !== undefined) formData.append('auto_import', options.autoImport ? 'true' : 'false');

  try {
    const response = await axios.post(
      '/api/payment-bill/local-bill-files/import',
      formData,
      {
        headers: {
          'Content-Type': 'multipart/form-data',
        },
        onUploadProgress: (progressEvent) => {
          const percentCompleted = Math.round((progressEvent.loaded * 100) / progressEvent.total);
          console.log('上传进度:', percentCompleted + '%');
        }
      }
    );

    return response.data;
  } catch (error) {
    if (error.response) {
      throw new Error(error.response.data.msg || '导入失败');
    }
    throw error;
  }
}

// 使用示例
const files = [/* File 对象数组 */];

uploadBillFiles(1, files, {
  force: false,
  autoImport: true
})
  .then(result => {
    console.log('导入成功:', result.data);
  })
  .catch(error => {
    console.error('导入失败:', error.message);
  });
```

## 📝 使用流程

1. **准备文件**
   - 从微信支付后台下载历史账单文件
   - 确保文件名包含日期（如 `2022-07-24_ALL.csv`）

2. **选择支付渠道**
   - 选择这些账单属于哪个支付渠道

3. **上传文件**
   - 可以一次性选择多个文件（数量受服务器配置限制）
   - 勾选"自动触发数据导入"可在上传后自动解析账单数据

4. **查看结果**
   - 系统会返回每个文件的详细处理结果
   - 成功的文件会在 `payment_bill_downloads` 表中创建记录

5. **后续处理**
   - 如果选择了自动导入，系统会自动将账单数据解析到 `payment_bill_wechat_bills` 表
   - 如果没有选择自动导入，可以稍后通过 `payment-bill:import` 命令或 API 手动触发

## 💡 最佳实践

1. **批量上传建议**
   - 建议每次上传 20-50 个文件
   - 文件过多时分批上传，避免超时

2. **命名规范**
   - 确保文件名包含日期信息
   - 推荐使用 `YYYY-MM-DD_ALL.csv` 格式

3. **错误处理**
   - 关注 `207` 状态码响应，表示部分文件失败
   - 检查 `details` 数组中的错误信息
   - 对失败的文件可以修正后重新上传

4. **性能优化**
   - 使用进度条显示上传进度
   - 大文件上传时考虑使用分片上传
   - 服务端配置合理的 `upload_max_filesize` 和 `post_max_size`

## ⚠️ 常见问题

### 文件名格式错误

**问题：** 提示"无法从文件名解析日期"

**解决：** 确保文件名包含以下格式之一：
- `YYYY-MM-DD_ALL.csv`（如 `2022-07-24_ALL.csv`）
- `YYYYMMDD.csv`（如 `20220724.csv`）

### 文件已存在

**问题：** 提示"已存在，跳过"

**解决：**
- 如需覆盖，勾选"强制覆盖"选项
- 或者先删除数据库中对应的记录

### 上传超时

**问题：** 上传大量文件时超时

**解决：**
- 减少单次上传的文件数量
- 增加服务器超时配置
- 检查网络连接

### 验证错误

**问题：** 提示"账单文件必须是 CSV 或 TXT 格式"

**解决：** 确保上传的文件扩展名是 `.csv` 或 `.txt`
